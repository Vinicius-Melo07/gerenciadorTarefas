# Gerenciador de Tarefas em Java

Projeto desenvolvido por mim para praticar os fundamentos da linguagem Java e os conceitos de Programação Orientada a Objetos.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas cadastradas
- Concluir tarefas pelo ID
- Remover tarefas pelo ID
- Validar entradas do usuário

## Tecnologias e conceitos

- Java
- usei o IntelliJ IDEA
- Programação Orientada a Objetos (POO)
- ArrayList
- Estruturas de repetição e condicionais
- Métodos e encapsulamento

Este projeto faz parte dos meus estudos de Java, com foco em lógica de programação.
